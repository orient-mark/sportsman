Приложение для спортсменов и других участников мероприятий, использующих систему отметки и хронометража [OrientMark](https://github.com/orient-mark).

## Установка

### Android

OrientMark Sportsman для Android устанавливается из APK-файла.

1. Подключитесь к интернету и откройте [последний выпуск](https://github.com/orient-mark/sportsman/releases/latest) на телефоне.
2. Разверните раздел **Assets** под описанием выпуска и скачайте файл приложения с расширением **`.apk`**.
3. Откройте скачанный файл из уведомления о завершении загрузки или из папки **«Загрузки»** в файловом менеджере.
4. Если Android запросит разрешение на установку из этого источника, нажмите **«Настройки»** и включите **«Разрешить из этого источника»** для браузера или файлового менеджера, из которого вы открыли APK.
5. Вернитесь к установке, нажмите **«Установить»**, а после завершения — **«Открыть»**.
6. В приложении включите сканер и разрешите доступ к камере **во время использования приложения**.

После установки сканирование QR, просмотр сохранённого сплита и передача результата работают без интернета. Данные участника и отметки сохраняются на телефоне и восстанавливаются после закрытия приложения.

Для обновления скачайте APK нового выпуска по той же ссылке и установите поверх текущей официальной версии. Предварительно удалять приложение не нужно: при обычном обновлении данные участника и отметки сохраняются. Обновления Android устанавливаются вручную.

Названия пунктов настроек могут отличаться в зависимости от телефона. Подробности установки из сторонних источников — в [справке Google](https://support.google.com/pixelphone/answer/7391672?hl=ru).

### iOS (iPhone)

OrientMark Sportsman устанавливается из Safari как веб-приложение (PWA).

1. Подключитесь к интернету и откройте [OrientMark Sportsman](https://orient-mark.github.io/sportsman/) в **Safari**. Если ссылка открылась внутри мессенджера, перейдите из него в Safari.
2. Нажмите **«Поделиться»** — значок квадрата со стрелкой вверх — и выберите **«На экран „Домой“»**. При необходимости прокрутите список действий вниз.
3. Оставьте название OrientMark и нажмите **«Добавить»**. Если отображается переключатель **«Открыть как веб-приложение»**, оставьте его включённым.
4. Запустите OrientMark через появившийся значок на экране «Домой», пока интернет ещё подключён.
5. Дождитесь сообщения **«Приложение готово к работе без интернета»** или **«Автономная версия доступна»**.
6. Откройте сканер и разрешите доступ к камере.

После этой подготовки сканирование QR, просмотр сохранённого сплита и передача результата работают без интернета. Перед соревнованиями проверьте, что приложение открывается через значок на экране «Домой» в авиарежиме.

Обновления загружаются автоматически, когда приложение открыто и подключено к интернету. Для установки обновления закройте сканер и вернитесь на главный экран приложения. Данные участника и отметки сохраняются; переустанавливать приложение не нужно.

Подробности меню Safari — в [инструкции Apple](https://support.apple.com/ru-ru/guide/iphone/iph42ab2f3a7/ios).

## Инструкция пользователя

**ПРИМЕЧАНИЕ:** перед использованием приложения проверьте разрешение на доступ к камере: оно необходимо для сканирования QR-кодов системы отметки.

После предоставления разрешения в приложении станет доступно сканирование QR-кодов.

**Для прохождения трассы:**

1. Включите сканер в главном меню приложения.
2. Сканируйте QR-коды меток. Отметка сопровождается звуком и анимацией зелёной галочки. Для подсветки QR-кода нажмите кнопку с молнией 🗲 в режиме сканирования, если она доступна. В версии для iOS доступность подсветки зависит от поддержки браузера и камеры.

**Для просмотра сплита:** 

1. Нажмите «Показать сплит» на главном экране.
2. В открывшемся окне можно перейти на вкладку передачи сплита организатору мероприятия.

**Для регистрации в системе отметки:**

1. Откройте настройки с главного экрана: нажмите кнопку в виде шестерёнки ⛭ вверху экрана.
2. Нажмите «Ввести данные пользователя» и отсканируйте код регистрации, предоставленный организатором.

### Ответы на вопросы

**Могу ли я выключать сканер при прохождении трассы?**

Да! Вы можете выключать работающий сканер. При сворачивании или закрытии приложения он тоже выключается. На длительных перегонах рекомендуется выключать смартфон для сохранения заряда устройства.

**Могу ли я закрыть приложение во время прохождения трассы?**

Да! Вы можете закрыть приложение и даже выключить смартфон. Отметки сразу сохраняются в постоянной памяти устройства, и сплит восстановится при повторном запуске приложения.

На iOS используйте приложение, установленное на экран «Домой». Перед удалением приложения или очисткой данных его сайта передайте результат организатору: эти действия могут удалить сохранённые записи.

**Могу ли я пройти трассу до регистрации в системе?**

Да! Вы можете пройти трассу до регистрации в системе и посмотреть свой сплит. Однако сплит не показывает правильность прохождения дистанции: для получения результата всё равно нужно передать его организатору трассы.

## Функции

- Регистрация пользователя с помощью специального QR-кода.
- Сканирование QR-кодов старта, финиша, контрольного пункта и очистки.
- Локальное хранение данных пользователя и его отметок.
- Отображение результата пользователя в виде серии QR-кодов.

## Разработка

Репозиторий: [orient-mark/sportsman](https://github.com/orient-mark/sportsman).
Ветка разработки: `dev`. Лицензия: [GPL-3.0](LICENSE).

Сборка рассчитана на Flutter 3.47.x / Dart 3.13.x. Android-конфигурация написана на Kotlin DSL (`.gradle.kts`): Gradle 9.3.1, Android Gradle Plugin 9.1.0, Kotlin 2.4.0, целевой байткод Java/Kotlin — 17.

Из каталога `sportsman` выполните:

```
flutter pub get
dart run build_runner build
flutter analyze
flutter build apk --debug
flutter run
```

В `android/gradle.properties` временно отключена инкрементальная компиляция Kotlin (`kotlin.incremental=false`). Это обходит ошибку кэша `mobile_scanner` на Windows, когда проект и Pub-кэш находятся на разных дисках. Повторная компиляция Kotlin может занимать больше времени; настройка не отключает hot reload Dart. После размещения проекта и Pub-кэша на одном диске можно убрать этот параметр, выполнить `flutter clean` и `flutter pub get`, затем проверить сборку заново.
