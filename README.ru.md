# sportsman

Приложение для спортсменов и других участников мероприятий, использующих систему отметки и хронометража [OrientMark](https://github.com/orient-mark).

## Инструкция пользователя

В настоящее время поддерживается только Android.

Скачайте APK-файл на своё устройство. Это прямая [ссылка](https://github.com/orient-mark/sportsman/releases/download/0.8.0/OrientMark-Sportsman-0.8.0.apk) для загрузки последней версии APK. Вы также можете выбрать подходящую вам версию из списка [выпусков](https://github.com/orient-mark/sportsman/releases).

**ПРИМЕЧАНИЕ:** перед использованием приложения проверьте разрешение на доступ к камере: оно необходимо для сканирования QR-кодов системы отметки.

После предоставления разрешения в приложении станет доступно сканирование QR-кодов.

**Для прохождения трассы:**
1. Включите сканер в главном меню приложения.
2. Сканируйте QR-коды меток. Отметка сопровождается звуком и анимацией зелёной галочки. Для подсветки QR-кода нажмите кнопку с молнией 🗲 в режиме сканирования.

**Для просмотра сплита:** 
1. Нажмите «Показать сплит» на главном экране.
2. В открывшемся окне можно перейти на вкладку передачи сплита организатору мероприятия.

**Для регистрации в системе отметки:**
1. Откройте настройки с главного экрана: нажмите кнопку в виде шестерёнки ⛭ вверху экрана.
2. Нажмите «Ввести данные пользователя» и отсканируйте код регистрации, предоставленный организатором.

### Ответы на вопросы

**Могу ли я выключать сканер при прохождении трассы?**

Да! Вы можете выключать работающий сканер. При сворачивании или закрытии приложения он тоже выключается. На длительных перегонах рекомендуется выключать смартфон для сохранения заряда устройства.

**Могу ли я закрыть приложение во время прохождения трассы?**

Да! Вы можете закрыть приложение и даже выключить смартфон. Отметки сразу сохраняются в постоянной памяти устройства, и сплит восстановится при повторном запуске приложения.

**Могу ли я пройти трассу до регистрации в системе?**

Да! Вы можете пройти трассу до регистрации в системе и посмотреть свой сплит. Однако сплит не показывает правильность прохождения дистанции: для получения результата всё равно нужно передать его организатору трассы.

## Функции

- Регистрация пользователя с помощью специального QR-кода.
- Сканирование QR-кодов старта, финиша, контрольного пункта и очистки.
- Локальное хранение данных пользователя и его отметок.
- Отображение результата пользователя в виде серии QR-кодов.

## Разработка

Репозиторий: [orient-mark/sportsman](https://github.com/orient-mark/sportsman).
Ветка разработки: `dev`. Лицензия: [GPL-3.0](LICENSE).

Сборка рассчитана на Flutter 3.47.x / Dart 3.13.x. Android-конфигурация написана на Kotlin DSL (`.gradle.kts`): Gradle 9.3.1, Android Gradle Plugin 9.1.0, Kotlin 2.4.0, целевой байткод Java/Kotlin — 17.

Из каталога `sportsman` выполните:

```
flutter pub get
dart run build_runner build
flutter analyze
flutter build apk --debug
flutter run
```

В `android/gradle.properties` временно отключена инкрементальная компиляция Kotlin (`kotlin.incremental=false`). Это обходит ошибку кэша `mobile_scanner` на Windows, когда проект и Pub-кэш находятся на разных дисках. Повторная компиляция Kotlin может занимать больше времени; настройка не отключает hot reload Dart. После размещения проекта и Pub-кэша на одном диске можно убрать этот параметр, выполнить `flutter clean` и `flutter pub get`, затем проверить сборку заново.
